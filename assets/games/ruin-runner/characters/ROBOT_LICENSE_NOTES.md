# RobotExpressive

- **Model:** RobotExpressive
- **Author:** Tomás Laulhé (Quaternius)
- **License:** CC0 1.0 Universal (public domain dedication)
- **Source:** https://github.com/mrdoob/three.js/tree/dev/examples/models/gltf/RobotExpressive
- **Local file:** `robot-expressive.glb`

Modifications by Don McCurdy, as noted by the original distribution:

- Added three facial-expression morph targets.
- Converted with FBX2GLTF.
- Removed duplicate materials and reduced material metalness.

The local integration additionally adjusts material metalness/roughness, adds a cyan face emissive and a cyan back-core effect, and uses the model's built-in `Idle`, `Running`, `Jump`, `Sitting`, and `Death` clips. These changes do not affect the CC0 status.
